## 🌟 Overview

A modern, responsive, and aesthetically pleasing personal portfolio website engineered specifically for computer science and engineering students. Designed using semantic HTML5 and clean, modular CSS3 with custom properties and responsive Flexbox/Grid layouts.

---

## 📑 Core Features & Implemented Sections

1. **Header & Navigation Bar**:
   - Sticky blur navbar with logo mark `</>`.
   - Smooth-scrolling anchor links: About, Skills, Projects, Achievements, Contact.
   - Distinct "Let's Talk" CTA button.

2. **Hero Section**:
   - Availability status indicator badge (`Available for Internships`).
   - Catchy typography with gradient heading.
   - Quick action buttons ("Explore Projects", "Get in Touch").
   - Student profile card with glowing avatar frame, academic affiliation, and quick metrics (15+ Projects, 400+ Problems Solved, 3+ Hackathons).
   - Social links to GitHub, LinkedIn, and Email.

3. **About My Journey**:
   - Academic education timeline highlighting B.Tech in Computer Science & Engineering.
   - Core interests and competencies (Responsive Development, UI/UX Design, AI Exploration).

4. **Technical Skills & Expertise**:
   - Categorized card grid:
     - **Frontend Development**: HTML5 Semantic, CSS3 Flexbox/Grid, JavaScript (ES6+), React.js.
     - **Programming & Backend**: Python, Java, SQL / PostgreSQL, Node.js, Data Structures.
     - **Tools & Workflow**: Git & GitHub, VS Code, Figma, Testing, Vercel/GitHub Pages.

5. **Featured Projects Showcase**:
   - Multi-column project card grid with hover zoom animation and overlays.
   - Detailed tags, description, status badge, and repository links.
   - Featured projects: Artisan Café, KeralaTrails Guide, EduVibe Online Course Portal.

6. **Honors & Achievements**:
   - Visual milestone cards for Hackathon awards, Web Development certifications, Dean's Merit Scholar, and competitive coding milestones.

7. **Contact & Inquiry Section**:
   - Direct communication cards (Email, GitHub, Location, Work availability).
   - Clean, interactive form with validated fields (Name, Email, Subject, Message).

8. **Footer**:
   - Copyright notice, navigational quick-links, and semantic credits.

## 🚀 How to Run Locally

1. Open `index.html` directly in any web browser (Google Chrome, Firefox, Edge, Safari).
2. Or serve using VS Code Live Server / Python HTTP server:
   ```bash
   python -m http.server 8000
   ```
   Open `http://localhost:8000` in your browser.
